# computer-network-project

A socket-based chat application for the Computer Network term project. A socket lets a program send and receive data over a network.

Status: documentation scaffold. The application is not implemented. The team has not selected a language, user interface, or AI feature.

## Start here

Read the [source documents and their ingestion record](docs/sources/README.md), then the [requirements and evidence map](docs/requirements.md).
The assignment requires separate client and server files. The demonstration needs two clients on different physical computers.
The team must explain the architecture, network protocols, and relevant code during the demonstration.
